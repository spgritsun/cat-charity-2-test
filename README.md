# QRKot — благотворительный фонд поддержки котиков

Приложение для Благотворительного фонда поддержки котиков. Фонд собирает
пожертвования на целевые проекты: закупку корма, обустройство кошачьей
колонии, медицинское обслуживание, регистрацию кошек как имущества.

## Как это работает

В фонде есть **целевые проекты** и **пожертвования**. Каждому проекту задаётся
требуемая сумма, каждое пожертвование приходит с суммой от жертвователя.
Средства распределяются автоматически, без ручного вмешательства:

- при создании нового проекта в него сразу переводятся все свободные
  (ещё не распределённые) деньги из ранее полученных пожертвований;
- при получении нового пожертвования деньги сразу распределяются
  по открытым проектам — от самых старых к новым.

Как только проект набирает требуемую сумму, он закрывается: у него
проставляются признак `fully_invested` и дата закрытия `close_date`.
Так же закрывается и пожертвование, все деньги которого разошлись по проектам.
Распределение и создание объекта выполняются одной транзакцией, поэтому
ситуация «проект создан, а деньги не распределились» невозможна.

## Возможности API

| Метод  | Эндпоинт                        | Что делает                          |
|--------|---------------------------------|-------------------------------------|
| GET    | `/charity_project/`             | Список всех целевых проектов        |
| POST   | `/charity_project/`             | Создать проект                      |
| PATCH  | `/charity_project/{project_id}` | Отредактировать проект              |
| DELETE | `/charity_project/{project_id}` | Удалить проект                      |
| GET    | `/donation/`                    | Список всех пожертвований           |
| POST   | `/donation/`                    | Сделать пожертвование               |

Ограничения при работе с проектами:

- название проекта уникально, длина от 5 до 100 символов;
- описание — не короче 10 символов;
- требуемая сумма — целое число больше нуля;
- закрытый проект редактировать нельзя;
- нельзя установить требуемую сумму меньше уже внесённой в проект;
- нельзя удалить проект, в который уже поступили средства.

Пожертвования не редактируются и не удаляются — по смыслу это уже
совершённое действие.

## Технологии

- Python 3.10+
- FastAPI
- SQLAlchemy 2.0 (асинхронный движок)
- Alembic
- Pydantic 2
- SQLite + aiosqlite
- pytest

## Установка и запуск

Клонировать репозиторий и перейти в его директорию:

```bash
git clone https://github.com/spgritsun/cat-charity-1.git
cd cat-charity-1
```

Создать и активировать виртуальное окружение:

```bash
python -m venv venv
source venv/bin/activate      # Linux / macOS
venv\Scripts\activate         # Windows
```

Установить зависимости:

```bash
pip install -r requirements.txt
```

Создать в корне проекта файл `.env`:

```
APP_TITLE=Благотворительный фонд поддержки котиков QRKot
DESCRIPTION=Сервис для поддержки котиков
DATABASE_URL=sqlite+aiosqlite:///./qrkot.db
```

Применить миграции:

```bash
alembic upgrade head
```

Запустить приложение:

```bash
uvicorn app.main:app --reload
```

Приложение будет доступно по адресу http://127.0.0.1:8000.

## Документация

После запуска доступна интерактивная документация:

- Swagger UI — http://127.0.0.1:8000/docs

## Тесты

```bash
pytest
```

Кроме тестов, в каталоге `postman_collection/` лежит готовая Postman-коллекция
`QRKot-1.postman_collection.json` — набор запросов для ручной проверки API.
Порядок запуска описан в `postman_collection/README.md`; коллекцию нужно
запускать на пустой базе.

## Структура проекта

```
app/
├── api/
│   ├── endpoints/    # обработчики запросов к проектам и пожертвованиям
│   ├── constants.py  # тексты сообщений об ошибках
│   ├── deps.py       # зависимости FastAPI (сессия БД)
│   ├── responses.py  # описания ответов с ошибками для Swagger
│   ├── routers.py    # сборка роутеров и теги документации
│   └── validators.py # проверки бизнес-правил
├── core/             # настройки приложения и подключение к БД
├── crud/             # операции с объектами в базе данных
├── models/           # ORM-модели CharityProject и Donation
├── schemas/          # схемы Pydantic для запросов и ответов
├── services/         # логика распределения средств между проектами
└── main.py           # точка входа

alembic/              # миграции базы данных
postman_collection/   # коллекция запросов для проверки API
tests/                # тесты
```
